Rules for the plan:
- Format and length: pick the format that ranks (explainer 600–1,200 words for a competitive concept, how-to 900–1,500 with an H3 per step, comparison 1,500–2,500, narrow guide 900–1,800, listicle 5–10 items) and calibrate it to the median length of the ranking pages. Lengths are guides, never quotas.
- Every H2 is a real search query or the plain name of what a searcher wants, and doesn't reuse the H1's question. The first H2 after Key Takeaways carries the core answer to the primary query.
- An H3 exists only if it passes the necessity test: the parent H2 holds two or more distinct sub-questions, a reader would scan for this one, and it can't be a paragraph. A sub-question becomes an H3 under its parent, never a sibling H2.
- Every question the H1 asks is answered in the first ~30% of the article (intro plus the first one or two H2s), by order and answer-first openers, never by cutting.
- Cover everything in Must Include, and give each Missing Opportunity a home. Every fact gets one home section.
- Depth per section follows the research: the Regulation Depth bullets set how much of a rule each section cites; a subtopic a published sdsmanager.com article already covers in depth gets a short treatment here and a link to it (Cannibalization).
- Map the keywords and anchors: name the section where each keyword from the keyword table and each anchor opportunity goes. No two adjacent sections carry an sdsmanager.com anchor.
- Write headings in Title Case. Write the planned article headings as plain lines prefixed with their level (`H2:`, `H3:`), not as Markdown headings, so this plan isn't mistaken for the article.
